How it works

Four steps, about two seconds.

Read the thread

The content script walks Intercom's DOM, including shadow roots, and labels every message as customer, agent, bot, or system.

Check the help center

Keywords from the latest customer message query your KB. The top three articles go into the prompt as the only allowed source.

Two calls in parallel

One Claude call writes the draft. A second writes the triage analysis. Promise.all means the analysis adds no wait.

Land it in the right place

Replies are pasted into Intercom's composer for review. Escalations go to a copy panel, never the customer-facing box.

Build story

Four versions, each one a lesson.

Built end to end by a support agent, not an engineer, using AI-assisted development. Every version shipped because the last one taught me something about how agents actually work.

v1Jan 2026

Python prototype, auto-fired

Generated a chat reply every time a conversation opened. One mode, one hardcoded prompt.

Lesson: drafts nobody asked for are noise, and they burn API spend. Agents want control, not autopilot.
v2Feb 2026

On-demand, multi-mode

Rewritten as explicit one-click actions with per-mode prompts, help center search, and a manual Insert fallback.

Lesson: the product isn't "AI replies". It's every message type a shift produces, each with its own format.
v3Mar to Apr 2026

Analysis panel, escalation safety, resilient selectors

Added parallel triage analysis, moved escalations out of the composer, and gave every DOM selector a fallback chain with built-in diagnostics.

Lesson: the riskiest failure was an internal escalation pasted where a customer could see it. Removing that path beat warning about it.
v4Oct 2026

Generalized for any Intercom workspace

Company, agent, and knowledge base became settings. Runtime host permissions replaced hardcoded domains. Updated for Intercom's new TipTap composer.

Lesson: a tool that only works for one team is a script. Configuration is what turns it into a product.

Setup

Running in three minutes.

  1. Get a Claude API keyCreate one at console.anthropic.com. A $5 credit covers hundreds of conversations.
  2. Load the extensionOpen chrome://extensions, turn on Developer mode, click Load unpacked, pick the folder.
  3. ConfigureIn the popup's Settings tab, add your key, name, company, and optionally your help center search URL.
  4. Open a conversationClick a mode. Review, tweak, send.
